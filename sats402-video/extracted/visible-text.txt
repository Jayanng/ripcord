          pay-per-request micropayments using native sats on Tachi. An agent pays
          for each call by signing its own transaction; the service verifies by
          reading the chain. Settlement is committed on-chain in about 5.5s (Tachi
          consensus finality). The HTTP round-trip is what the agent sees.

[h2] Built for the agent economy, on Bitcoin
[p] Sats402 is the x402
[code] exact
[p] scheme on Tachi: the wire format the
      standard defines, settled as a Tachi transaction. The money moves exactly
      once, and the proof of payment is a transaction id anyone can check.
[span] For agents
[h3] A spending policy is part of the SDK
[p] Per-call cap, session budget, payee allowlist. A call that breaks policy
        is refused locally, before any transaction exists.
[span] For services
[h3] One middleware, zero custody
[p] Drop the paywall in front of any handler. It issues the challenge and
        verifies payment by reading the chain. It never holds a key.
